WordPress block theme

1776, built from scratch

A hand-written WordPress theme with custom blocks, a portfolio post type and a plugin-free contact form. The demo runs a real WordPress site in your browser, so nothing is installed and nothing is saved.

Open the live demo Read the code

Things to try in the demo

  • Browse Work to see the Project Grid block and the single project template with its Project Details block.
  • Send a message from Contact, then find it under Messages in the admin (you are logged in as admin).
  • Open Appearance → Editor to edit templates, try the Midnight style variation, or insert the theme's patterns.
  • Edit a project to see the Project details meta box and the custom blocks in the 1776 inserter category.
The demo loads in a few seconds the first time. It uses WordPress Playground, which runs PHP and WordPress in WebAssembly.
